# Disentangling Highly Entangled Grouped Data 

**Abstract:** Group-instance disentanglement is the problem of learning separate representations for within-group and across-group variability. The current state-of-the-art methods for solving this problem are based on the Multi-Level Variational Autoencoder (ML-VAE). In this work, we create a synthetic dataset wherein the group and instance variables cannot be inferred accurately from a single datapoint. We use this dataset to show that models from the ML-VAE family are limited in how they 1) define the variational distribution of the instance variable, and 2) use adversarial training to prevent the instance encoder from encoding group information. We overcome this failure case by modifying the encoder and loss function of the ML-VAE.

## Background

We review the current methods for group-instance disentanglement

[[bouchacourt_2018]] proposed the original model, with evidence accumulation by multiplication, no conditioning in the instance variable and no regularization for the instance variable.

[[hosoya_2019]] have developed this concurrently with [[bouchacourt_2018]], but they use evidence accumulation by averaging instead of product

[[nemeth_2020]] add an adversarial loss for regularization which differentiates between $(x,s)$ pairs coming from the same group and pairs coming from different groups.

The instance variable is inferred only from its respective datapoint. So in cases where the same datapoint could belong to different groups, and thus have different instance variables, the model cannot infer that.

In the same spirit, the regularizer has to determine if $(x,s)$ belong to the same group without knowing what the group is. The same pair could belong to one group, just not the group which is currently analysed.

**In the existing methods, the instance variable is computed independentely of the grouping which, counter-intuitively, makes it depenent on the grouping**

## Problem
Why can the instance variable be difficult to infer from a single datapoint? Because the same datapoint could have different group factors, and thus different instance factors.

In the ML-VAE paradigm, the variational distribution of the instance variable $q(\textbf{v}_k^n | \textbf{x}_k^n)$ is conditioned only on the corresponding datapoint. Therefore, if two datapoints from different groups happen to have the same value, but different instance factors, the instance encoder has no way of infering a different instance distribution for each datapoint.

In fact, when factorizing the generative latent posterior $p(\textbf{u}^n, \underline{\textbf{v}}^n | \underline{\textbf{x}}^n)$ into a group term and an instance term, we can either condition the instance on the group like $$p(\textbf{u}^n | \underline{\textbf{x}}^n) \prod_{k=1}^{K_n} p(\textbf{v}_k^n | \textbf{x}_k^n)$$ **(proof of this in appendix)** or condition the group on the instance $$p(\textbf{u}^n | \underline{\textbf{x}}^n) \prod_{k=1}^{K_n} p(\textbf{v}_k^n | \textbf{x}_k^n)$$

We show that these methods cannot disentangle in situations where the instance variable cannot be inferred from a single datapoint.

## Dataset

We derive such a problem case, with ground truth group and instance variables. Our dataset consists of scalar datapoints, real numbers.

$$N=8192, ~ K^n \sim 8 + \text{Poisson}(\lambda=16)$$

$$\textbf{u}^n := (\textbf{u}_\mu^n, \textbf{u}_\sigma^n), ~ \textbf{u}_\mu^n \sim \mathbb{N}(0, 2), ~ \textbf{u}_\sigma^n \sim \mathbb{N}(0, 1)$$

$$\textbf{v}_k^n \sim \mathbb{N}(0, 1)$$

$$\textbf{x}_k^n = \textbf{u}_\mu^n + \textbf{u}_\sigma^n * \textbf{v}_k^n$$

In this dataset, each datapoint could have come from any group, with the corresponding instance variable changing for every group.

This is a dataset in which the group and instance variable are marginally independent. However, they are not independent when conditioned on the datapoint. In fact, the variance of $p(\textbf{v}|\textbf{x})$ is very high, whereas the variance of $p(\textbf{v}|\textbf{x},\textbf{u})$ is very low.

### Diagnostic
In order to quantify the disentanglement in the model, we use 2 metrics: the performance of the model at translation, and the distribution of instance variables over groups.

#### Translation
Translation is the process of changing the value of one of the latent variables whilst keeping the other's value fixed. In practice, we infer the latent variables from a data group (A), and replace its group variable with the group variable inferred from a different data group (B). We then generate a datapoint for each instance variable from group A, but using the group variable from group B.

The connection between translation and group-instance disentanglement is well-established ==Look up papers which draw this parallel== and translation is often used as a metric for disentanglement. ==Look up papers which have used translation to measure disentanglement==

==Why does a good translation require good disentanglement==

Since we are using a synthetic dataset, we can measure translation accuracy precisely by creating the ground truth translation for every pair of testing groups A B. We do that by taking the mean and variance of group B and the individual instance variables of group A.

To measure the translation accuracy quantitatively, we take the mean squard error between each translated datapoint and its ground truth.

#### Distribution of instance variables across groups
As pointed out in [[nemeth_2020]], disentanglement usually fails when the instance variable encodes part of the group information. (It doesn't usually happen the other way around because instance information is different for every datapoint in the group and so is not useful in the group variable) One way to verify whether the instance variable learns group information is to inspect how much the empirical distribution of inferred instance codes changes from across data groups. The smaller the change, the less likely it is that the instance variable encodes group information.

## Context VAE
In  order to mitigate these problems, we change the instance encoder and the regularizer to make both of them group-conditional.
- If we follow the derivation of the variational distrbution, **and we choose to infer first the group variable and then the instance variable**, the resulting instance inference distribution will be conditioned on the group variable. This is already present in **the work on sequences**. We claim that the only way instances from separate groups can be disambiguated is through knowledge of the group
- We then apply the same change to the adversarial network described in [[nemeth_2020]].
