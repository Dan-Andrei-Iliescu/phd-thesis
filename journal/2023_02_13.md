### Intepretation

So what happens if we have one big datapoint with different features instead of a bag of features?

Take the XOR function. Z = A x B. No single value from the input can predict anything about the output, yet knowing both allow you to predict perfectly. So wait, A and Z variables have no mutual information, but they are not independent, since A has mutual information with A,B, which has mutual information with Z. Contrast this with Z = A + B, where 

$$I(Z;A,B) = \mathrm{KL} [P(Z,A,B) || P(Z) ~ P(A,B)]$$
$$= \mathrm{KL} [P(Z, A, B) || P(Z) ~ P(A) ~ P(B)]$$
$$= \mathbb{E}_{P(A,B)}[\log P(A) P(B) - \log P(Z) - \log P(A)P(B)]$$
$$= - \mathbb{E}_{P(Z)} \log P(Z) = H(Z)$$

If $Z = A \cdot B$:
$$I(Z ; A) = \mathrm{KL} [P(Z,A) || P(Z) P(A)] = 0$$

If $Z = A + B$:
$$I(Z ; A) = \mathrm{KL} [P()]$$
