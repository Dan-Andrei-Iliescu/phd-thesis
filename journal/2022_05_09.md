## Exam-score model

I need to find as many papers as possible that use this exact model, in order to add weight to the experiment showing that the conditional model disentangles whereas the unconditional model doesn't. I want the reader to think "They are solving the disentanglement problem on this highly important and yet simple model" instead of "They are just inventing a model to fit their needs".

So the question is, how do I evaluate this model? The first test is how well it fits the holdout dataset, and I measure that by reconstruction loss. The second thing is how well it disentangles, how well the variation in the data is separated and captured, and I measure this using the mutual information between the inferred latents and the true latents. The third thing is how well it translates, how well it answers the counterfactual question "What if this student went to that school". The final thing is how well do the inferred latents match the true latents, basically how good is it at estimating the true generative factors, and I measure this using the log likelihood of the true generative factors.

## Paper argument

We propose a form for the variational posterior that allows the group VAE to learn disentangled representations of data generated by the varying slope varying intercept multilevel model on which existing Group VAEs cannot disentangle. Our method relies on conditioning the instance variable on the group variable. Additionally we show that by varying the amount of conditional shift in the data generating process we can affect the performance gain of our proposed model: when there is no conditional shift, the conditional and unconditional models perform equally well. However, as the conditional shift increases, the performance of the unconditional model decreases, while the conditional model stays relatively constant. This is the first step towards amortised inference and generation of data from novel groups at test time in mixed-effects models.
