Bridging the gap between causal inference, representation learning, missing value imputation and domain generalisation. The paper will be called "Representing Partial Observations". Many works in the causal representation learning literature assume that there is a 1:1 mapping between the observation and the latent factor, at least this is how the dataset is constructed. But what if the same observation can correspond to multiple values for the latent factors? This is a far more common occurence in real-world data. We propose to condition the instance representation on the group representation.

### Abstract 

We propose a novel group-disentanglement method called the Context-Aware Variational Autoencoder (CxVAE). Our model can learn disentangled representations on datasets with conditional shift. This phenomenon occurs when the conditional distribution of the instance-level latent variable $\mathbf{z}$ given the input observation $\mathbf{x}$ changes from one group to another (i.e. $p_i(\mathbf{z}|\mathbf{x}) \neq p_j(\mathbf{z}|\mathbf{x})$, where $i,j$ are two different groups). We show that existing methods fail to learn disentangled representations under this scenario because they infer the group $\mathbf{u}$ and instance $\mathbf{z}$ variables separately. CxVAE overcomes this limitation by conditioning the instance inference on the group variable $q(\mathbf{z}|\mathbf{x},\mathbf{u})$. Our model has the novel ability to disentangle ambiguous observations (those with incomplete information about the generative factors), which we evaluate empirically on high-dimensional image datasets. Additionally, we demonstrate that conditional shift is the cause of our model's ability to disambiguate.

### Evaluation

In the first part of the evaluation, we show that our model has a set of new abilities over existing methods. These abilities enable our model to perform important tasks in new circumstances that better reflect the real world. Each ability is applicable everywhere, but we exemplify it with tasks where it's easiest to understand.

1. Disambiguation. This means that the same datapoint could have been generated by many combinations of group and instance values. This is relevant in a straightforward disentanglement task where the group and instance variables come out as entangled in a normal model. We also use translation to show visually how this happens.
2. Dynamic Reasoning. This is conditional shift in the abstract visual reasoning task.
3. Generalisation. If the representation is used as a feature extractor for a predictor, this predictor is  able to perform well on out-of-distribution groups. Here we compare with existing domain generalisation methods, and also with using Group VAEs as feature extractors. We use holdout set prediction error to test our method.

In general, we compare with Group VAE, MLVAE and Ada-GVAE.

In the second part of the evaluation, we demonstrate that the size of our model's performance gain is determined by the amount of conditional shift in the dataset.

For this, we use a generated standardised test score dataset where the amount of conditional shift can be modified at will.
