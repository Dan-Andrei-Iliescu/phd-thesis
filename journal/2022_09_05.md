## Vision

Bridging the gap between causal inference, representation learning, missing value imputation and domain generalisation. The paper will be called "Representing Partial Observations". Many works in the causal representation learning literature assume that there is a 1:1 mapping between the observation and the latent factor, at least this is how the dataset is constructed. But what if the same observation can correspond to multiple values for the latent factors? This is a far more common occurence in real-world data. We propose to condition the instance representation on the group representation.
