## Damon's comment - 2023-12-06

I've been thinking a bit more about domain shift and your
group-instance work. In causal inference, the goal is typically to learn the structural equation models, so that we can predict the response variable uniformly well (or uniformly badly) in any domain.

This sort of model is the best we can hope for when we're making
predictions for an entirely unseen domain. But if we're making
predictions for a domain that we've seen before (or that we have
few-shot data for), then we ought to be able to do better than the pure causal predictor. In your language: if the dataset is
disentangled then we can identify the group from a single instance; if the dataset is entangled then we can identify the group from several instances; if we have identified the group then we ought to be able to use non-causal predictors.

From what I've seen of the domain-shift literature, they don't cleanly separate the two concerns. From what I've seen of the causal inference literature, it is concerned purely with learning the causal predictor. I think that your group-instance work might offer a clean way to combine causal prediction with non-causal prediction, to the extent it's safe to.
