# Shut Up and Write
*2021-12-09*

- Talk to supervisor about what chapters are necessary in the thesis.
- Example: Start writing in May for completion in October.
- Put a concrete date to it.
- Reward yourself after completing a task.

### Techniques for starting to write
- Start with the easiest chapter, so that you get yourself going.
- **Free writing:** write for 10 minutes about anything without stopping.
  - ex: How does my work fit into the larger research area.
  - ex: Free write about what I will be going to write.
- **Writing to prompts:** Building a research summary by answering question prompts (about 50 words per prompt).
- **Story boards:** Place results visually in order and for each write caption about what it means.
- **Mind maps:** Connect concepts and chapters.
- **Writing in layers:** Chapter headings -> section headings -> paragraph headings. Write 1-2 sentences at each level.
- Mark things to check at the end using todos.
