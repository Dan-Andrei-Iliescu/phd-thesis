- A Gaussian Process is a prior probability density over the joint distribution of outputs $$\mathbf{f}$$ in both the training and testing sets. This prior probability is a Gaussian of mean $$0$$ and covariance matrix defined by the __distance__ between the inputs $$\mathbf{x}$$ in both the training and testing sets.
    - $$\begin{bmatrix} \mathbf{F} \\ \mathbf{F}' \end{bmatrix} \sim \mathcal{N} \left( \begin{bmatrix} \mathbf{0} \\ \mathbf{0} \end{bmatrix} , \begin{bmatrix} \mathbf{K}_{\mathbf{X} \mathbf{X}} ~ \mathbf{K}_{\mathbf{X} \mathbf{X}'} \\ \mathbf{K}_{\mathbf{X} \mathbf{X}'} ~ \mathbf{K}_{\mathbf{X}' \mathbf{X}'} \end{bmatrix} \right)$$
    - $$\mathbf{K}_{\mathbf{X} \mathbf{X}'} [i,j] = k(\mathbf{x}_i, \mathbf{x}'_j ; \theta)$$. This is the covariance matrix built with a kernel function $$k$$ with hyperparameter $$\theta$$.
    - The target is obtained by adding noise to the outputs: $$\mathbf{Y} \sim \mathcal{N} (\mathbf{F}, \sigma^2 \mathbf{I})$$. We can simplify this analytically: $$\mathbf{Y} \sim \mathcal{N} (\mathbf{0}, \mathbf{K}_{\mathbf{X} \mathbf{X}} + \sigma^2 \mathbf{I})$$.
- Non-parametric means there are as many parameters as there are datapoints.
    - More formally, GPs contain countably infinite many parameters that define the regression function, which are the function values $$f$$ at all possible inputs $$\mathbf{x} \in \mathcal{X}$$.
